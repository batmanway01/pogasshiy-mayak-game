# Погасший маяк

2D dark fantasy в духе Souls на Godot 4. Воскрешённый Страж Артур поднимается к погасшему маяку: Склеп, Мост, Тронный зал и бой с Верраном.

Босс Верран учится по ходу боя: угадывает твой стиль (Байес) и выбирает атаку на шаг вперёд (Expectimax). Чем однообразнее играешь, тем точнее он тебя ловит.

## Скачать

**[Последняя версия → Releases](../../releases/latest)** — файл `PogasshiyMayak_v0.3.zip` (≈111 МБ, Windows 10/11, 64 бит).

## Как запустить

1. Распакуй архив в любую папку (не запускай прямо из архива).
2. Запусти `PogasshiyMayak.exe`. Файлы `.exe` и `.pck` должны лежать рядом.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае». Игра не подписана, поэтому так.
4. «Новая игра» → выбери сложность: Лёгкий, Средний (как задумано) или Сложный.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / Shift | идти / бежать |
| J | удар (3 подряд — комбо) |
| L | сильный удар |
| Q | блок (держать) |
| K | перекат, в начале ты неуязвим |
| H | пепельная фляга |
| E | очаг, находки |
| U / I | Вспышка / Огненный клинок (тратят Жар) |
| F1 | «Память Веррана»: что босс думает о тебе |
| Esc | пауза и настройки |
